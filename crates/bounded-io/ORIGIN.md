# Physical intake origin

The bounded stream/error contract is derived from Hatter utils/path-utils/src/bounded.rs.
Hatter downstream modification attribution and original Apache-2.0 LICENSE/NOTICE are retained.
This local prototype has no publication, owner policy, semantic retention, network or default limits.
rustix supplies OS flags and owned handles. Caller adapters retain existing error categories and budgets.
Windows intake adds standard reparse-point flags and safe winapi-util disk-handle checks. Runtime/cross-target evidence and remaining limitations are recorded separately.
